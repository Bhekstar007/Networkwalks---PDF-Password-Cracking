# PDF Password Cracking – Cybersecurity Practical Labs

## Overview

This repository documents a series of practical cybersecurity exercises focused on PDF password recovery and password-cracking techniques.

The project explores different approaches to recovering passwords from protected PDF documents using command-line tools, graphical interfaces and web-based utilities. It also investigates AI-assisted workflows to understand how artificial intelligence can support security-related tasks.

The practical exercises cover **W3-PM1 and W3-PM2**, providing hands-on experience with password hashes, dictionary-based attacks and password recovery techniques.

## Objectives

The primary objectives of this project were to:

- Understand how password-protected PDF documents work.
- Explore PDF password hash extraction and identification.
- Gain practical experience with John the Ripper.
- Compare command-line and graphical password-cracking workflows.
- Experiment with web-based password recovery tools.
- Explore AI-assisted cybersecurity workflows.
- Analyse and document the results obtained through different approaches.

## Methodology

The practical exercises explored multiple approaches to PDF password recovery.

### 1. PDF Hash Extraction

The first stage involved working with password-protected PDF documents and extracting their corresponding password hashes for further analysis.

### 2. John the Ripper

John the Ripper was used to explore password-cracking techniques, including dictionary-based attacks against extracted PDF password hashes.

### 3. Johnny GUI

Johnny provided a graphical alternative to interacting with John the Ripper. This allowed for experimentation with password-cracking workflows through a graphical interface.

### 4. Networkwalks

Networkwalks was used as an additional approach to explore web-based password recovery techniques and compare the results with locally executed tools.

### 5. AI-Assisted Experimentation

Hexstrike and Claude were explored as part of an AI-assisted approach to cybersecurity exercises.

This involved experimenting with prompts, tool interactions and analysing the outputs generated during the password-recovery process.

This repository is intended strictly for **educational and cybersecurity training purposes**.
